# 에코월드 방문객 지도 v7.0 배포 안내

배포용 파일은 `ecoworld-v7.0-github-pages.zip`이다. 압축을 풀면 `index.html`, `assets/` 안의 모델 6개, 이 안내문이 나온다. 폴더 구조를 유지해 기존 GitHub Pages 경로에 올린다. 이번 작업에서는 배포하지 않았다.

- MapLibre GL JS 6.15.0과 Three.js 0.186.1을 버전이 고정된 jsDelivr CDN에서 읽는다. ESM을 지원하는 최신 브라우저와 WebGL2가 필요하다.
- 페이지를 열면 바로 지도가 뜬다. 별도 지도 엔진 인증 입력은 없다.
- 일반지도는 브이월드 Base, 항공사진은 Satellite이다. 기존 키(값 생략)를 사용한다. 등록 도메인은 지시서 기준 `https://dsadfa137.github.io`이다.
- 브이월드의 지원 줌은 6~19이다. 앱은 22까지 확대할 수 있고 19 이후에는 19레벨 타일을 확대한다. 확대 시 화질은 더 좋아지지 않는다.
- 화면의 `© 국토교통부 브이월드`와 기존 공개 도형의 출처표시를 유지한다.
- 키의 운영 승인 상태·만료일·개별 호출 한도·영리 목적 이용 동의 적용 여부는 확인 불가이다. 공개 운영 전에 계정 및 운영기관을 통해 확인한다. 공식 근거는 개발 작업폴더에 별도로 제공한 `qa/v7.0-sources.md`를 참고한다(QA 자료는 ZIP에 포함하지 않음).
- GPS는 HTTPS와 브라우저 위치 권한이 필요하다. 위치 이력은 저장하지 않는다. 길 스냅은 기존 검증 대상 선분만 사용하며 KML 참고 동선은 경로 보정에 쓰지 않는다.
- 모델은 사진·영상 기반 시각적 추정이며 현장 측량 결과가 아니다. 6개 모델의 형상·좌표·방향·축척은 v6.9 자료를 유지한다.
- 개별 모델이 실패하면 해당 모델만 단순 건물로 돌아간다. 지도 설정의 다시 불러오기 버튼으로 재시도한다.

개발 시 `app-template.html`과 각 `*-runtime.js`, `poi-labels.js`를 수정한 뒤 `node build.cjs`를 실행한다. 생성된 `index.html`은 직접 수정하지 않는다. build는 모델을 다시 만들지 않으며 보존 해시가 달라지면 중단한다. 이후 모든 루트 `check*.cjs`를 실행한다. QA 자료는 배포 ZIP에 포함하지 않는다.
